# DZ DUB MOTION

واجهة عربية تجريبية لتحضير برومبتات مشاهد فيديو صامتة جاهزة للدبلجة اليدوية.

## التشغيل
- افتح `index.html` مباشرة في المتصفح.
- لا يحتاج إلى تثبيت أو خادم.

## المزايا
- نص إلى مشهد / صورة إلى مشهد.
- اختيار المدة والأبعاد والأسلوب وحركة الكاميرا.
- تعليمات صارمة بعدم وجود حوار أو تحريك شفاه.
- نسخ البرومبت أو تنزيله كملف TXT.
- تصميم متجاوب للهاتف والكمبيوتر.

## ملاحظة
هذه النسخة لا تولّد ملفات MP4 بنفسها. ربط خدمة توليد فيديو يتطلب API ومفتاحاً من مزود خارجي، وقد تكون الخدمة مدفوعة أو محدودة مجاناً.
